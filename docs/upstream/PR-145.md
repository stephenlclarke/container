# Pull request handoff: bound concurrent VM boot pressure

## Summary

- Admit runtime bootstraps through a FIFO actor with a ceiling of 15 or the active processor count, whichever is lower.
- Limit only Virtualization.framework and guest bootstrap while preserving concurrency in lifecycle capture, logging preparation, launchd registration, runtime-client creation, and state publication.
- Return capacity after success, failure, or cancellation, including cancellation racing with permit transfer.
- Record admission wait separately from runtime bootstrap duration in debug timing metadata.

## Code map

- `Sources/Services/ContainerAPIService/Server/Containers/RuntimeBootstrapLimiter.swift` implements cancellation-safe FIFO admission.
- `Sources/Services/ContainerAPIService/Server/Containers/ContainersService.swift` applies the limiter only around runtime bootstrap and separates admission from execution timing.
- `Tests/ContainerAPIServiceTests/ContainerBootstrapConcurrencyTests.swift` covers the concurrency ceiling, failure release, and queued cancellation.
- `docs/upstream/ISSUE-144.md` records the diagnosis, required behavior, acceptance evidence, and parent-contract boundary.

## Release benchmark

The seven-repetition, warm-image, counterbalanced comparison froze the Compose binary, Containerization plugins, OCI image, Docker oracle, fixtures, host, and schedule. The benchmarked production source was commit `731f195c3f800a451d4026f29985e69367899d79`; the reviewed head differs only by a bounded-wait test improvement and evidence documentation.

Functional parity passed and every candidate median and P95 remained below the 10x Docker guard. Fifty-service startup median improved from 16.411s to 8.542s, a 47.9 percent reduction. P95 improved from 22.674s to 12.944s, a 42.9 percent reduction. Docker-normalized fifty-service median improved 45.9 percent.

One-service startup median improved 1.8 percent. Ten-service startup median changed by 1.0 percent. The limiter therefore removes the measured high-concurrency saturation cliff without a material normal-workload regression.
