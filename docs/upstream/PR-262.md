# Pull request handoff: install the complete Homebrew runtime

## Summary

- Install the signed `container-engine` gateway from the release archive.
- Install the complete `libexec/container` tree instead of retaining only plugins.
- Assert the gateway, semantic helper, and journald/GELF service archives in
  the formula test.
- Add a template regression so generated stable and lane formulae cannot
  silently lose the required assets.

## Motivation and Context

`container system start` now supervises the runtime-neutral Container Engine
gateway. The release archive already packages and signs that gateway and its
supporting helper/service assets, but the Homebrew formula discarded them at
install time. This made the enhanced distribution unusable through the
supported Homebrew path and caused Docker-less devcontainer parity startup to
fail before the public Engine socket could bind.

Fixes <https://github.com/stephenlclarke/container/issues/261>.

## Design choices

Homebrew installs the whole staged `libexec/container` directory. That
directory is already the signed package boundary assembled by the Makefile,
so installing a hand-maintained subset would allow future runtime assets to be
omitted again. The top-level `ensure-container-stopped.sh` remains a separate
`libexec` installation because it is outside that runtime directory.

The formula test checks the gateway and representative helper/service assets.
The Python regression checks the maintained template itself, which also
covers every generated stable or development formula produced by
`update-homebrew-formula.py`.

## Compatibility

This is additive at install time and does not change the Container CLI or
Apple runtime APIs. Existing plugin installation paths remain unchanged. Disk
usage increases only by assets that were already part of the signed release
archive and are required by the corresponding runtime build.

## Remaining risks

The stable and Current tap formulae now contain the corrected complete-runtime
installation. Existing installations still require a Homebrew reinstall or
upgrade to receive the changed formula. Installed-prefix runtime startup and
Engine health have not been re-certified in this handoff record.
