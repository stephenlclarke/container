# Pin the coverage-compatible Containerization revision

## Change

Resolve #281 by advancing the immutable Containerization dependency from
`4c95face06701be6572c92db34ca1864329c7b69` to reviewed merge
`51bf8a10e2036861f87ccdf2fd881a8726c534d2` from
[Containerization #102](https://github.com/stephenlclarke/containerization/pull/102).

The lower-repository change supports the per-target `.xctest` bundles emitted
by Xcode 27 and Swift 6.4 while retaining the historical aggregate layout.
Container library and runtime source remain unchanged.

## Validation

- `swift package resolve --disable-sandbox` selects the exact new revision and
  leaves every other resolved dependency unchanged.
- `swift build --target ContainerRuntimeClient
  --disable-automatic-resolution` passes.
- `git diff --check` passes.
- Hosted required checks and exact-head review are required before merge.

## Compatibility

Stock Apple runtime behaviour, Container CLI behaviour, and Compose parity are
unchanged. The dependency update changes only coverage generation used by
quality and release gates.

## Remaining risk

The downstream Compose stack must pin the resulting Container merge and the
same Containerization merge before resuming stable publication.
