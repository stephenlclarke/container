# PR 264: restore the enhanced BuildKit contract

This change resolves issue 263 by pinning the immutable builder-shim image that
accepts `--dns-nameserver`, `--dns-option`, and `--dns-search-domain`.

The pull request also adds an architecture-emulated CI check of the actual
pinned OCI image. Source-level unit tests remain responsible for checking the
arguments emitted by the Swift runtime; the image probe checks the other side
of that contract.
